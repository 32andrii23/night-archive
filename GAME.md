# Ночной архив

Сетевая дуэль для двух человек. Посетитель исследует архив от первого лица, собирает три предохранителя, включает рубильник и выходит за 4 минуты. Архивариус видит тактическую карту, перемещается по тем же проходам и должен поймать посетителя или задержать его до конца таймера.

## Вход

1. Посетитель нажимает «Создать комнату» и копирует выданную ссылку.
2. Второй человек открывает полную ссылку и занимает роль архивариуса. Если он уже открыл главную страницу, на экране роли можно вставить полную ссылку приглашения. На стартовом экране эту роль можно открыть скрытой кнопкой в правом верхнем углу; кнопка доступна с клавиатуры при фокусе.
3. Приглашение содержит выданный сервером одноразовый ключ роли. Код комнаты сам по себе не даёт прав. После первого входа архивариуса ссылка повторно место не занимает; для переподключения нужен тот же браузер.

## Управление

- Посетитель: клик по сцене захватывает курсор для обзора мышью; удержание левой кнопки ведёт вперёд, правой — назад. `Esc` освобождает курсор. Если браузер запрещает захват, обзор работает перетаскиванием с зажатой кнопкой, а удержание кнопки по-прежнему ведёт. `WASD` движут относительно взгляда, `←/→` поворачивают, `E` взаимодействует, `F` включает вспышку, `M` открывает план. На плане можно проложить маршрут кликом.
- Архивариус: `WASD`/стрелки или клик по карте — движение, `E` — обыск шкафа, `1–3` — отключить свет в секторе, `4` — заклинить выход, `5` — проявиться. Ложный стук выбирается кнопкой и точкой на карте.
- Звук включается после первого действия в браузере. Есть регулировка громкости, mute и щадящий режим. Щадящий режим убирает резкие визуальные и звуковые скримеры.

## Устройство

- Cloudflare Worker/Vinext обслуживает UI и `/api/game`; D1 хранит комнаты и серверное состояние.
- Для каждого действия сервер проверяет токен роли, правила движения, расстояния, ресурс и время восстановления. Состояние обновляется с проверкой версии D1 для защиты от одновременных ходов.
- Посетителю не раскрываются далёкие предметы и невидимый архивариус; архивариус получает координаты посетителя лишь рядом с ним или в активных камерах.
- Вид посетителя построен из геометрии Three.js: реальные стены, пол, стеллажи, книги, шкафы, камеры, предохранители и архивариус. Повторяющиеся детали объединены в `InstancedMesh`; две небольшие процедурные текстуры создаются один раз, модели и внешние текстуры не загружаются. Тени отключены, разрешение ограничено бюджетом пикселей, частота кадров снижается в ожидании и при щадящем режиме. Three.js загружается только для посетителя. Карта архивариуса остаётся двумерным интерфейсом наблюдения.

## Локальная проверка

```sh
npm ci
npm run db:generate
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_handy_whirlwind.sql
npm run dev
node scripts/smoke-game.mjs
```
